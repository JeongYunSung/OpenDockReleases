# Memory Book

흩어진 사진과 한 줄 메모를 억지로 꾸미지 않고 사실을 보존한 채 읽기 좋은 기록으로 만듭니다. 캡션, 월간 회고, 여행기와 연말 기록처럼 원하는 형태로 발전시킬 수 있습니다.

## 이런 때 사용하세요

- 여행이나 가족 행사를 기록으로 남길 때
- 사진에 짧은 캡션과 날짜를 붙일 때
- 한 해의 중요한 순간을 회고할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-memory-book` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Memory Book 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 사진과 메모를 날짜순으로 정리하고 과장 없이 짧은 여행기로 써줘.

> 올해 기록에서 사람, 장소, 배운 점을 뽑아 연말 회고로 만들어줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 날짜와 출처를 잃지 않은 추억 타임라인
- 사진에 어울리는 자연스러운 캡션
- 공유용 글과 개인 보관용 상세 기록
