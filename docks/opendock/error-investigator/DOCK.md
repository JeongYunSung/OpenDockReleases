# Error Investigator

로그 한 줄만 보고 추측하지 않고 증상, 재현 조건, 환경 차이와 최근 변경을 순서대로 확인합니다. 임시 해결과 근본 해결을 구분하고 같은 문제가 다시 생기지 않도록 테스트까지 연결합니다.

## 이런 때 사용하세요

- 원인을 모르는 오류가 반복될 때
- 내 컴퓨터에서는 되는데 다른 환경에서 실패할 때
- 수정 후 같은 오류를 막는 테스트를 남기고 싶을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-error-investigator` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Error Investigator 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 에러 로그를 기준으로 재현 조건과 가능한 원인을 우선순위대로 조사해줘.

> macOS에서는 되지만 Windows에서 실패하는 이유를 환경 차이부터 확인해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 증상과 근거가 연결된 원인 분석
- 최소 범위의 수정과 재현 가능한 확인 절차
- 재발을 막는 회귀 테스트와 운영 메모
