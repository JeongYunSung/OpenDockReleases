# Mobile Ultrawork

작은 화면에서 보인다는 것뿐 아니라 터치 영역, 키보드, safe area, 오프라인, 권한 거부와 앱 생명주기를 함께 봅니다. 강한 검수를 요청하면 현재 변경을 실제 모바일 사용 흐름 기준으로 엄격하게 확인합니다.

## 이런 때 사용하세요

- iOS, Android, Flutter, React Native 기능을 구현할 때
- 권한, 딥링크, 백그라운드 동작을 다룰 때
- 작은 화면과 접근성, 오프라인 상태를 검수할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-mobile-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Mobile Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 사진 권한을 사용하는 프로필 수정 화면을 거부 상태까지 구현해줘.

> 이번 모바일 변경을 ultrawork로 검수해서 작은 화면, 키보드, safe area, 권한과 생명주기 문제를 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 모바일 상태와 권한 흐름을 포함한 구현
- 플랫폼 차이를 고려한 테스트
- 현재 기능의 화면·접근성·생명주기 검수 결과
