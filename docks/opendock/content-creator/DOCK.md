# Content Creator

주제만 받아 문장을 길게 늘리는 대신 독자, 목적, 핵심 주장과 근거를 먼저 정합니다. 같은 메시지를 채널마다 어울리는 구조와 말투로 바꾸고 게시 전 확인 사항까지 챙깁니다.

## 이런 때 사용하세요

- 블로그나 뉴스레터 초안을 만들 때
- 긴 자료를 짧은 SNS 글이나 영상 대본으로 바꿀 때
- 여러 콘텐츠의 톤과 핵심 메시지를 맞출 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-content-creator` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Content Creator 기준으로”라고 적어도 됩니다.

### 요청 예시

> OpenDock 소개 글을 개발자가 아닌 팀장도 이해할 수 있는 블로그 글로 써줘.

> 이 인터뷰를 뉴스레터와 60초 영상 대본으로 각각 바꿔줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 독자와 채널에 맞는 콘텐츠 초안
- 주장과 근거가 분리된 편집 가능한 구조
- 제목, CTA, 게시 전 확인 목록
