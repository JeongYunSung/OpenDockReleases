# Group Trip

친구나 가족 여행에서 가장 어려운 예산, 음식, 이동량과 하고 싶은 일의 차이를 먼저 정리합니다. 누구 한 사람의 취향만 따르지 않고 공통 선호와 충돌 지점을 보여준 뒤 현실적인 타협안을 만듭니다.

## 이런 때 사용하세요

- 여러 명의 여행 취향을 한 번에 정리할 때
- 예산과 활동 선호가 서로 다를 때
- 각자 선택할 수 있는 자유 시간과 공통 일정을 나눌 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-group-trip` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Group Trip 기준으로”라고 적어도 됩니다.

### 요청 예시

> 네 명의 선호를 비교해서 공통 일정, 선택 일정, 충돌 항목을 정리해줘.

> 부모님은 적게 걷고 아이는 체험을 원해. 모두가 만족할 3일 일정을 만들어줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 구성원별 선호와 제약 비교
- 합의가 필요한 항목과 추천 타협안
- 공통 일정과 선택 일정을 나눈 여행 계획
