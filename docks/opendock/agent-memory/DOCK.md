# Agent Memory

대화가 길어질수록 중요한 결정이 묻히거나 새 대화에서 같은 설명을 반복하게 됩니다. 이 Dock은 오래 남겨야 할 사실, 임시 메모, 폐기할 정보를 구분해 AI가 다시 읽기 좋은 기억으로 정리합니다.

## 이런 때 사용하세요

- 프로젝트의 결정과 이유를 다음 대화에서도 이어가고 싶을 때
- 긴 회의나 작업 기록에서 꼭 남길 내용만 추릴 때
- 오래된 기억과 충돌하는 최신 결정을 정리할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-agent-memory` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Agent Memory 기준으로”라고 적어도 됩니다.

### 요청 예시

> 오늘 결정한 API 정책 중 다음 작업에서도 기억해야 할 내용만 정리해줘.

> 기존 프로젝트 메모에서 오래됐거나 서로 충돌하는 내용을 찾아 최신 상태로 정리해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 다음 작업에 바로 쓸 수 있는 짧은 기억
- 사실과 가정, 만료된 정보를 구분한 기록
- 민감정보를 제외한 재사용 가능한 프로젝트 맥락
