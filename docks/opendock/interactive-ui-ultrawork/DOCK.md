# Interactive UI Ultrawork

화려한 효과를 덧붙이는 것이 아니라 사용자가 상태 변화를 이해하고 다음 행동을 알 수 있게 모션을 설계합니다. 강한 검수를 요청하면 키보드, reduced motion, 터치, 프레임 성능과 화면 가림을 현재 인터랙션에서 엄격하게 확인합니다.

## 이런 때 사용하세요

- 페이지 전환, 드래그, 스크롤 반응을 만들 때
- 로딩과 성공·실패 피드백을 자연스럽게 표현할 때
- 과한 모션과 접근성·성능 문제를 잡을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-interactive-ui-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Interactive UI Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 업로드 진행 상태를 사용자가 이해하기 쉬운 인터랙션으로 구현해줘.

> 이번 모션을 ultrawork로 검수해서 키보드, reduced motion, 모바일 터치와 성능 문제를 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 행동과 상태를 설명하는 목적 있는 모션
- 키보드와 터치를 고려한 인터랙션
- 현재 인터랙션의 접근성·성능 검수 결과
