# Backend Ultrawork

백엔드 기능을 만드는 데서 끝나지 않고 요청 검증, 트랜잭션, 오류 응답, 권한, 데이터 정합성까지 함께 봅니다. 평소에는 현재 기능에 집중하고, 강한 검수를 요청하면 관련 코드와 테스트를 엄격하게 확인합니다.

## 이런 때 사용하세요

- 새 API나 배치 작업을 구현할 때
- DB 변경이 포함된 기능의 실패와 롤백을 확인할 때
- 인증, 권한, 입력 검증 누락을 잡고 싶을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-backend-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Backend Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 주문 취소 API를 구현하고 중복 요청과 결제 실패까지 처리해줘.

> 이번 주문 API 변경을 ultrawork로 검수하고 발견한 문제를 테스트와 함께 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 실패 상황까지 고려한 백엔드 구현
- API 계약과 데이터 정합성을 확인하는 테스트
- 현재 작업 범위에 대한 명확한 검수 결과
