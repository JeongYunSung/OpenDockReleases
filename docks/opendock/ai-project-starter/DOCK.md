# AI Project Starter

AI 도구를 열 때마다 프로젝트 설명과 작업 방식을 다시 알려줄 필요가 없도록 기본 맥락을 준비합니다. 팀의 목표, 코딩 또는 문서 규칙, 자주 쓰는 작업 흐름을 AI가 바로 이해할 수 있게 정리합니다.

## 이런 때 사용하세요

- 새 프로젝트에서 Codex나 Claude Code를 바로 쓰고 싶을 때
- 팀마다 다른 AI 작업 규칙을 하나로 맞출 때
- 기존 프로젝트에 최소한의 AI 안내만 추가하고 싶을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-ai-project-starter` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “AI Project Starter 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 React 프로젝트를 분석해서 AI가 따라야 할 최소 규칙과 주요 작업 흐름을 만들어줘.

> 우리 팀의 리뷰 방식과 금지 사항을 반영해 AI 프로젝트 시작 설정을 정리해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 프로젝트 목적과 구조를 이해하는 AI 안내
- 반복 작업에 쓸 수 있는 간결한 작업 흐름
- 기존 파일을 함부로 덮지 않는 안전한 기본 설정
