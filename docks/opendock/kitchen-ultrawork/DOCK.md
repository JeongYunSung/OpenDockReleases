# Kitchen Ultrawork

재료 목록만 나열하지 않고 인원, 도구, 알레르기, 보관 상태와 가능한 시간을 먼저 확인합니다. 강한 검수를 요청하면 양, 온도, 교차오염, 대체 재료와 조리 순서를 현재 레시피 기준으로 엄격하게 봅니다.

## 이런 때 사용하세요

- 냉장고 재료로 가능한 요리를 찾을 때
- 인원과 식단 제한에 맞춰 레시피를 조정할 때
- 대량 조리나 보관 과정의 안전을 확인할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-kitchen-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Kitchen Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 닭가슴살, 양배추, 달걀로 2인 저녁을 30분 안에 만들 수 있게 알려줘.

> 이 도시락 레시피를 ultrawork로 검수해서 보관 시간, 알레르기, 조리 온도와 양을 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 재료와 시간에 맞는 단계별 레시피
- 대체 재료와 실패를 줄이는 조리 팁
- 현재 레시피의 식품 안전과 양 검수 결과
