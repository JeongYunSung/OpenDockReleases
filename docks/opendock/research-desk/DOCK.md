# Research Desk

검색 결과를 이어 붙이지 않고 질문을 쪼개고 출처의 신뢰도와 날짜를 확인합니다. 서로 다른 주장과 확인되지 않은 부분을 드러내 사용자가 판단할 수 있는 자료로 정리합니다.

## 이런 때 사용하세요

- 제품, 시장, 기술 주제를 깊게 조사할 때
- 여러 출처의 주장이 서로 다를 때
- 인용과 근거가 필요한 보고서를 만들 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-research-desk` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Research Desk 기준으로”라고 적어도 됩니다.

### 요청 예시

> AI agent memory 시장을 공식 문서, 논문, 사용자 경험으로 나눠 조사해줘.

> 이 세 자료의 공통 주장과 충돌하는 내용을 출처와 함께 비교해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 질문별로 정리된 조사 결과
- 주장과 근거, 해석, 미확인 사항의 구분
- 출처 링크와 확인 날짜가 포함된 리서치 노트
