# Security Privacy Ultrawork

패턴 검색만 돌리는 데서 끝나지 않고 데이터가 어디서 들어와 어디로 나가는지, 누가 어떤 권한으로 실행하는지 확인합니다. 강한 검수를 요청하면 현재 변경의 공격 경로와 실제 피해 가능성을 우선순위별로 검증합니다.

## 이런 때 사용하세요

- 인증과 권한이 포함된 기능을 변경할 때
- 개인정보나 사내 데이터를 AI 또는 외부 서비스에 보낼 때
- 의존성, secret, prompt injection 위험을 검수할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-security-privacy-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Security Privacy Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 업로드 API의 인증, 파일 검증, 저장 경로와 개인정보 위험을 검토해줘.

> 이번 변경을 ultrawork로 보안 검수하고 실제 악용 가능한 문제를 테스트와 함께 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 영향과 악용 조건이 분명한 보안 문제
- 민감정보 흐름과 권한 경계 정리
- 현재 변경 범위의 수정·재검증 결과와 남은 위험
