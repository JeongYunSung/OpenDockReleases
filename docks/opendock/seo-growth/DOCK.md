# SEO Growth

키워드를 반복해서 넣는 대신 사용자의 검색 의도, 페이지 역할과 실제 콘텐츠를 먼저 봅니다. 제목, 설명, heading, 내부 링크, sitemap, robots와 OG 정보를 함께 점검합니다.

## 이런 때 사용하세요

- 새 사이트의 SEO 기본 구조를 만들 때
- 검색 유입이 낮은 페이지를 개선할 때
- 메타태그, sitemap, robots와 OG 이미지를 확인할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-seo-growth` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “SEO Growth 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 SaaS 랜딩의 검색 의도와 핵심 키워드를 정하고 제목과 설명을 개선해줘.

> 사이트의 기술 SEO를 점검해서 index를 막는 문제와 콘텐츠 개선 항목을 나눠줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 페이지 목적에 맞는 제목과 설명
- 검색 의도를 반영한 콘텐츠 구조
- 기술 SEO 문제와 측정 가능한 개선 계획
