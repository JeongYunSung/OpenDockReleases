# Docs Ultrawork

문장이 자연스러운지만 보지 않고 명령어, 파일 경로, 옵션, 버전과 실제 동작이 맞는지 확인합니다. 강한 검수를 요청하면 빠른 시작부터 링크, 다국어 문서, 오래된 표현까지 현재 변경 범위에서 엄격하게 점검합니다.

## 이런 때 사용하세요

- README와 사용자 가이드를 새로 쓸 때
- 코드 변경 뒤 문서가 뒤처졌는지 확인할 때
- 깨진 링크, 오래된 명령, 다국어 차이를 찾을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-docs-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Docs Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 CLI의 README를 처음 쓰는 사람이 5분 안에 실행할 수 있게 다시 써줘.

> 이번 문서 변경을 ultrawork로 검수해서 실제 명령과 다른 부분, 깨진 링크, 번역 누락을 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 처음부터 따라 할 수 있는 빠른 시작
- 현재 코드와 일치하는 명령과 설정 설명
- 링크, 구조, 다국어 일관성에 대한 검수 결과
