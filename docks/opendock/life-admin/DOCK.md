# Life Admin

매달 또는 매년 반복되지만 흩어져 있어 놓치기 쉬운 일을 정리합니다. 민감한 원문을 그대로 저장하기보다 무엇을 언제 확인해야 하는지와 필요한 문서 위치만 기록합니다.

## 이런 때 사용하세요

- 구독과 자동 결제를 정리할 때
- 여권, 보험, 보증기간과 갱신일을 관리할 때
- 가족 또는 가정의 반복 업무를 달력처럼 정리할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-life-admin` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Life Admin 기준으로”라고 적어도 됩니다.

### 요청 예시

> 내 구독 목록을 월간 비용과 갱신일 기준으로 정리하고 해지 후보를 알려줘.

> 올해 만료되는 서류와 보증을 월별 체크리스트로 만들어줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 갱신일과 담당 행동이 명확한 생활 업무 목록
- 반복 비용과 놓치기 쉬운 기한 요약
- 민감정보 없이 유지할 수 있는 연간 체크리스트
