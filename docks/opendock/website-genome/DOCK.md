# Website Genome

사이트의 겉모습을 따라 그리는 대신 반복되는 시각 규칙과 화면 구조를 분석합니다. 디자인 시스템 초안, 경쟁사 비교와 리디자인 기준으로 재사용할 수 있는 결과를 만듭니다.

## 이런 때 사용하세요

- 좋아하는 사이트의 디자인 원리를 분석할 때
- 기존 제품에서 디자인 토큰을 추출할 때
- 두 사이트의 구조와 시각 언어를 비교할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-website-genome` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Website Genome 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 사이트의 색상 역할, 타이포그래피, 간격, 그리드와 컴포넌트를 분석해줘.

> 경쟁사 두 곳의 랜딩 구조와 디자인 패턴을 비교하고 우리 제품에 참고할 원칙만 뽑아줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 사이트의 시각 규칙과 화면 구조 분석
- 재사용 가능한 디자인 토큰과 컴포넌트 목록
- 복제가 아닌 원칙 중심의 개선 방향
