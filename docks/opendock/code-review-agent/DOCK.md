# Code Review Agent

코드 스타일만 지적하는 리뷰가 아니라 실제 동작 오류, 보안 위험, 회귀 가능성과 빠진 테스트를 찾는 데 사용합니다. 사람이 최종 판단하기 전에 변경 범위를 빠르게 훑는 보조 리뷰어입니다.

## 이런 때 사용하세요

- Pull Request를 올리기 전에 위험한 변경을 찾을 때
- 큰 diff에서 중요한 문제부터 정리할 때
- 리뷰 결과를 수정 작업과 테스트로 연결할 때

## 설치되는 도구

- 프로젝트 전용 PR Agent CLI를 준비합니다.
- 사용할 수 있는 명령: `pr-agent`
- 도구는 현재 프로젝트에서 OpenDock이 추적하므로 다른 프로젝트의 전역 환경과 섞이지 않습니다.

## AI에서 이렇게 사용하세요

AI에서 `$opendock-code-review-agent` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Code Review Agent 기준으로”라고 적어도 됩니다.

### 요청 예시

> 현재 변경분을 리뷰해서 실제 버그 가능성이 높은 문제부터 알려줘.

> 이 PR에서 인증 우회나 데이터 손실 위험과 빠진 테스트를 찾아줘.

## 사용 후 얻는 것

- 심각도와 근거가 포함된 리뷰 목록
- 수정 위치와 재현 조건이 구체적인 피드백
- 리뷰 후 추가해야 할 테스트 제안

## 알아둘 점

자동 리뷰는 병합 승인 자체를 대신하지 않으며, 중요한 변경은 사람이 diff와 테스트 결과를 함께 확인해야 합니다.
