# Packing Assistant

모든 여행에 같은 준비물 목록을 쓰지 않고 기간, 계절, 세탁 가능 여부, 활동과 수하물 제한을 반영합니다. 출발 직전까지 확인해야 할 항목과 현지에서 살 수 있는 항목을 나눕니다.

## 이런 때 사용하세요

- 여행 준비물을 빠르게 만들 때
- 겨울, 등산, 온천처럼 특별한 활동이 있을 때
- 기내와 위탁 수하물을 나눠야 할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-packing-assistant` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Packing Assistant 기준으로”라고 적어도 됩니다.

### 요청 예시

> 2월 홋카이도 5일 여행과 온천 일정에 맞는 준비물을 만들어줘.

> 이 목록을 기내용, 위탁용, 출발 당일 챙길 것으로 나눠줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 날씨와 활동에 맞는 준비물 목록
- 수하물 위치와 수량을 고려한 분류
- 출발 전 마지막 확인과 현지 구매 후보
