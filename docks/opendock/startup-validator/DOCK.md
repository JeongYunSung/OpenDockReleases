# Startup Validator

기능을 많이 계획하기 전에 어떤 고객이 어떤 문제 때문에 돈이나 시간을 쓰는지 확인합니다. 사실, 가정, 희망을 분리하고 인터뷰, 랜딩, 수동 운영 같은 작은 실험으로 검증 순서를 정합니다.

## 이런 때 사용하세요

- 새 사업 아이디어가 실제 문제인지 확인할 때
- MVP에서 무엇을 빼야 할지 정할 때
- 고객 인터뷰와 검증 실험을 설계할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-startup-validator` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Startup Validator 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 아이디어의 고객, 문제, 기존 대안과 가장 위험한 가정을 정리해줘.

> 2주 안에 돈을 거의 쓰지 않고 수요를 검증할 실험과 성공 기준을 만들어줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 검증 가능한 문제와 고객 가설
- 위험도 순으로 정리된 핵심 가정
- 기간, 비용, 성공 기준이 있는 작은 실험 계획
