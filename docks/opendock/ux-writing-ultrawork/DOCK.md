# UX Writing Ultrawork

개발자 용어나 번역투를 그대로 노출하지 않고 사용자가 지금 무엇을 해야 하는지 이해하게 만듭니다. 프로젝트의 WRITING 기준을 우선하며, 강한 검수를 요청하면 현재 문구의 명확성, 일관성, 오류 회복과 한영 품질을 엄격하게 확인합니다.

## 이런 때 사용하세요

- 버튼, 메뉴, 오류 메시지와 온보딩 문구를 만들 때
- 개발자스러운 용어를 서비스 말투로 바꿀 때
- 한국어와 영어 문구의 의미와 톤을 맞출 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-ux-writing-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “UX Writing Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 설정 화면의 기술 용어를 일반 사용자도 이해할 수 있는 문구로 바꿔줘.

> 이번 한영 UI 문구를 ultrawork로 검수해서 모호한 행동, 번역투, 용어 불일치를 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 사용자가 다음 행동을 이해하는 짧은 문구
- 제품 기준에 맞는 한국어·영어 용어와 톤
- 현재 문구의 명확성·일관성·회복 안내 검수 결과
