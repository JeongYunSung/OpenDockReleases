# Moving

이사 직전에 몰아서 처리하지 않도록 해야 할 일을 날짜 역순으로 배치합니다. 버릴 것, 가져갈 것, 새로 살 것과 업체 연락 사항을 나눠 누락과 중복 비용을 줄입니다.

## 이런 때 사용하세요

- 이사 준비 일정을 처음 만들 때
- 주소 변경과 공과금 이전을 빠뜨리지 않으려 할 때
- 가구 치수와 구매·폐기 목록을 함께 관리할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-moving` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Moving 기준으로”라고 적어도 됩니다.

### 요청 예시

> 8월 30일 이사 기준으로 D-30부터 당일까지 해야 할 일을 정리해줘.

> 현재 집 물건을 가져갈 것, 버릴 것, 새로 살 것으로 나누고 예산을 계산해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 날짜별 이사 준비 일정
- 주소, 공과금, 업체 연락 체크리스트
- 구매·폐기·운반 항목과 예상 비용
