# Agent Planning

복잡한 요청을 한 번에 던지면 AI가 중간 목표를 놓치기 쉽습니다. 해야 할 일, 순서, 의존 관계, 완료 조건을 먼저 정리해 실제로 실행 가능한 계획으로 바꿉니다.

## 이런 때 사용하세요

- 여러 파일과 역할이 얽힌 작업을 시작할 때
- 중간에 요구사항이 바뀌어 계획을 다시 맞춰야 할 때
- 무엇이 끝났고 무엇이 남았는지 명확히 보고 싶을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-agent-planning` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Agent Planning 기준으로”라고 적어도 됩니다.

### 요청 예시

> 회원가입 개편을 디자인, 프론트엔드, 백엔드, QA 단계로 나누고 완료 조건까지 정리해줘.

> 현재 진행 상황을 기준으로 막힌 일과 다음에 할 일을 다시 계획해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 순서와 의존 관계가 보이는 작업 목록
- 각 단계의 완료 조건과 확인 방법
- 변경 사항을 반영한 최신 진행 계획
