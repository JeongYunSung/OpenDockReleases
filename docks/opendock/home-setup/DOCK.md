# Home Setup

예쁜 가구 목록보다 실제 공간의 크기와 사용 순서를 먼저 봅니다. 이미 가진 물건, 꼭 필요한 것, 나중에 살 것을 구분해 중복 구매와 치수 실수를 줄입니다.

## 이런 때 사용하세요

- 자취방이나 새 집을 처음 세팅할 때
- 재택근무 공간을 따로 만들 때
- 방별 구매 순서와 예산을 정할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-home-setup` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Home Setup 기준으로”라고 적어도 됩니다.

### 요청 예시

> 10평 원룸을 재택근무에 맞게 세팅해줘. 예산은 200만원이고 수납이 중요해.

> 이 방 치수와 보유 가구를 기준으로 꼭 사야 할 것과 나중에 살 것을 나눠줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 공간별 우선순위와 배치 기준
- 치수와 예산을 포함한 구매 목록
- 중복 구매와 생활 동선 문제를 줄이는 체크리스트
