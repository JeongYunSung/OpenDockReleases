# Korea Macro Research

한 가지 지표로 경기를 단정하지 않고 서로 연결된 거시 지표의 방향과 시차를 봅니다. 최신 공식 통계의 기준일을 남기고 가능한 시나리오와 확인해야 할 다음 지표를 구분합니다.

## 이런 때 사용하세요

- 한국 경제의 현재 흐름을 이해할 때
- 금리와 환율 변화가 업종과 가계에 미치는 영향을 볼 때
- 서로 다른 경제 전망의 근거를 비교할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-korea-macro-research` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Korea Macro Research 기준으로”라고 적어도 됩니다.

### 요청 예시

> 최근 한국의 물가, 기준금리, 원달러 환율을 연결해서 현재 경기 상황을 설명해줘.

> 금리 인하가 시작될 경우 부동산, 은행주, 소비에 미칠 영향을 시나리오별로 정리해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 기준일과 출처가 있는 거시경제 요약
- 지표 사이의 관계와 시차 설명
- 낙관·기준·위험 시나리오와 다음 확인 항목
