# Data Ultrawork

쿼리가 실행되는지만 보지 않고 지표 정의, 날짜와 시간대, null 처리, 중복 집계와 개인정보 노출까지 확인합니다. 강한 검수를 요청하면 현재 분석 결과를 재현성과 의사결정 가능성 기준으로 엄격하게 봅니다.

## 이런 때 사용하세요

- 새 지표와 SQL을 만들 때
- 대시보드 수치가 원천 데이터와 맞는지 확인할 때
- 비용이 큰 쿼리나 개인정보 노출 위험을 찾을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-data-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Data Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 월간 활성 사용자 지표를 정의하고 검증용 SQL까지 만들어줘.

> 이 매출 대시보드를 ultrawork로 검수해서 중복 집계와 시간대 오류를 찾아 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 정의와 계산 방식이 명확한 지표
- 재현 가능한 SQL과 검증 결과
- 데이터 품질, 비용, 개인정보 위험 목록
