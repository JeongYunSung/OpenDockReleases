# Trip Planner

장소를 많이 넣는 대신 이동 시간, 휴식, 예약, 식사와 비 오는 날 대안을 함께 봅니다. 최신 정보가 필요한 항목은 출처와 다시 확인할 시점을 표시합니다.

## 이런 때 사용하세요

- 여행 전체 일정을 처음 만들 때
- 부모님, 아이, 적은 보행 같은 제약이 있을 때
- 예산과 예약 상태, 우천 대안을 함께 관리할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-trip-planner` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Trip Planner 기준으로”라고 적어도 됩니다.

### 요청 예시

> 10월 교토 4박을 부모님과 가. 하루 8천 보 이하로 동선과 우천 대안을 짜줘.

> 예약한 호텔과 식당을 기준으로 이동 시간과 하루 예산을 포함한 일정을 만들어줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 무리하지 않는 날짜별 일정과 이동 시간
- 예산, 예약, 준비물과 우천 대안
- 최신 정보를 다시 확인해야 할 시점과 출처
