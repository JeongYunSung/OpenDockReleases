# Launch Ultrawork

기능 개발이 끝났다는 이유만으로 바로 공개하지 않고 사용자가 처음 만나 결제하고 도움을 받는 전체 흐름을 확인합니다. 강한 검수를 요청하면 현재 서비스의 누락된 상태와 운영 위험을 우선순위별로 잡습니다.

## 이런 때 사용하세요

- 새 서비스나 큰 기능을 공개하기 전
- 랜딩과 가격, 온보딩 메시지를 맞출 때
- 결제, 분석, 오류 상태와 고객지원 준비를 확인할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-launch-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Launch Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이번 SaaS 오픈에 필요한 랜딩, 가격, 온보딩, 분석 체크리스트를 만들어줘.

> 현재 서비스를 ultrawork로 검수해서 공개를 막는 문제와 오픈 후 보완할 문제를 나눠 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 사용자 여정 전체를 보는 공개 준비 목록
- 즉시 해결할 차단 문제와 후속 개선 항목
- 결제·분석·오류·지원 흐름의 현재 상태
