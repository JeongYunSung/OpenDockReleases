# Portfolio Case Study

화면 이미지를 나열하는 대신 어떤 문제를 발견했고 왜 그 해결책을 선택했는지 보여줍니다. 실제 기여와 결과를 과장하지 않고 독자가 빠르게 이해할 수 있는 흐름으로 정리합니다.

## 이런 때 사용하세요

- 디자인 또는 제품 프로젝트를 포트폴리오로 만들 때
- 팀 성과와 개인 기여를 구분할 때
- 수치가 부족한 프로젝트의 결과를 정직하게 표현할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-portfolio-case-study` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Portfolio Case Study 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 프로젝트 자료를 배경, 문제, 조사, 판단, 결과, 회고 순서의 케이스 스터디로 만들어줘.

> 내 기여가 모호한 부분과 근거 없이 과장된 문장을 찾아 자연스럽게 고쳐줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 문제와 해결 과정이 이어지는 이야기
- 개인 기여와 팀 결과를 구분한 설명
- 포트폴리오 페이지와 면접에 재사용할 핵심 요약
