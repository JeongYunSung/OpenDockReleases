# Browser Agent

페이지 내용을 설명하는 데 그치지 않고 실제 브라우저에서 이동, 입력, 클릭, 캡처 같은 작업을 자동화할 때 사용합니다. 반복되는 웹 확인이나 공개 페이지 조사에 특히 유용합니다.

## 이런 때 사용하세요

- 여러 페이지를 돌아다니며 같은 정보를 수집할 때
- 폼 입력이나 화면 흐름을 실제 브라우저로 확인할 때
- 스크린샷과 함께 웹 동작 결과를 남길 때

## 설치되는 도구

- 프로젝트 안에서 사용하는 브라우저 자동화 CLI를 준비합니다.
- 사용할 수 있는 명령: `agent-browser`
- 도구는 현재 프로젝트에서 OpenDock이 추적하므로 다른 프로젝트의 전역 환경과 섞이지 않습니다.

## AI에서 이렇게 사용하세요

AI에서 `$opendock-browser-agent` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Browser Agent 기준으로”라고 적어도 됩니다.

### 요청 예시

> 공개된 가격 페이지 세 곳을 열어 플랜과 제한을 표로 비교해줘.

> 회원가입 화면을 처음부터 끝까지 따라가며 막히는 단계와 화면을 기록해줘.

## 사용 후 얻는 것

- 브라우저에서 직접 확인한 최신 정보
- 클릭과 입력 순서가 포함된 재현 가능한 기록
- 필요한 화면 캡처와 실패 지점

## 알아둘 점

로그인, 결제, 게시처럼 계정이나 외부 상태를 바꾸는 작업은 실행 전에 사용자의 확인을 받아야 합니다.
