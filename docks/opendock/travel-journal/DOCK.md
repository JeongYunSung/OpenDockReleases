# Travel Journal

기억나지 않는 내용을 만들어내지 않고 사진 시간, 장소와 메모를 바탕으로 사실을 먼저 정리합니다. 개인 보관용 상세 기록, 공유용 짧은 글과 사진 캡션으로 나눌 수 있습니다.

## 이런 때 사용하세요

- 여행 사진과 메모가 흩어져 있을 때
- 날짜별 여행 기록을 만들 때
- 블로그나 SNS용 짧은 여행기를 만들 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-travel-journal` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Travel Journal 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이 사진과 메모를 날짜별로 정리하고 확인되지 않은 장소는 질문해줘.

> 여행 기록을 블로그 글과 사진별 짧은 캡션으로 각각 만들어줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 사실과 날짜를 보존한 여행 타임라인
- 사진에 맞는 캡션과 하이라이트
- 개인 기록과 공유용 글을 나눈 최종 결과
