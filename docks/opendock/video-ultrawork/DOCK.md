# Video Ultrawork

장면을 무작정 이어 붙이지 않고 대상, 메시지, 길이와 배포 채널을 먼저 정합니다. 강한 검수를 요청하면 현재 영상의 가독성, 자막, 음량, 저작권 기록과 출력 규격을 엄격하게 확인합니다.

## 이런 때 사용하세요

- 제품 데모나 짧은 설명 영상을 만들 때
- 대본과 스토리보드를 영상으로 연결할 때
- 자막, 음성, 화면 비율과 최종 파일을 점검할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-video-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Video Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> OpenDock 설치 과정을 45초 제품 데모 영상으로 기획하고 만들어줘.

> 이번 영상을 ultrawork로 검수해서 자막 가독성, 음량, 화면 비율과 권리 기록을 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 목적과 길이에 맞는 대본과 장면 구성
- 자막과 음향이 포함된 재생 가능한 영상
- 현재 영상의 기술 규격·접근성·권리 검수 결과
