# UX 리뷰랩

설치한 프로젝트에서 화면의 사용성을 점검하는 일반 Dock입니다. 빠른 점검, 역할별 리뷰, 선택적 예상 주목도 맵을 제공합니다. 자동 수정 도구나 독립 에이전트 실행 엔진은 포함하지 않습니다.

## 프로젝트 로컬 설치

모든 manifest의 `to`는 설치 대상 프로젝트를 기준으로 한 상대 경로입니다.

| 내용 | 설치 위치 |
| --- | --- |
| Codex 스킬과 AI 표시 정보 | `.agents/skills/opendock-ux-review-lab/` |
| Claude Code 스킬 | `.claude/skills/opendock-ux-review-lab/SKILL.md` |
| 사용 안내, 기능별 가이드, 출처 | `.opendock/docks/ux-review-lab/` |
| 요청 라우팅과 안전 지침 | 프로젝트 `AGENTS.md`의 OpenDock 관리 영역 |

사용자 홈의 전역 스킬 디렉터리에는 복사하지 않습니다. 전역 패키지, 외부 CLI, 서비스, MCP 연결도 설치하지 않습니다. 기존 `.agents/`를 다른 도구가 관리하는 프로젝트에서는 직접 복사하거나 덮어쓰지 말고 해당 호스트와 OpenDock의 관리·충돌 처리 절차를 따르세요.

Codex에서는 `$opendock-ux-review-lab`, Claude Code에서는 `/opendock-ux-review-lab`을 사용합니다. 두 경로의 스킬은 같은 원본에서 설치되며 기능별 가이드는 공용 경로에 한 번만 설치합니다. Claude Code용 `CLAUDE.md`나 설정 파일을 덮어쓰지 않으며, 스킬 로딩을 위해 별도 전역 설치나 심볼릭 링크를 요구하지 않습니다.

1.0.0에는 Claude Code 경로가 없었습니다. 1.0.1 이상으로 업데이트하면 프로젝트의 Claude 스킬 파일과 해당 doctor 검사가 추가됩니다. 처음 `.claude/skills/` 폴더가 생성되었다면 Claude Code를 다시 시작하고 `/opendock-ux-review-lab`을 확인하세요. 이 경로는 로컬 Claude Code용이며 Claude 웹 채팅이나 Cowork의 계정 스킬 업로드와는 별개입니다.

## 기능과 결과

| 요청 | 적용 가이드 | 결과 |
| --- | --- | --- |
| 별도 기능 선택 없음 | 빠른 점검 + 역할별 리뷰 | 중복을 합친 UX 문제와 개선안 |
| 빠른 점검만 | [QUICK_REVIEW.md](QUICK_REVIEW.md) | 이해·행동·혼란 지점 중심의 짧은 리뷰 |
| 역할별 리뷰만 | [ROLE_REVIEW.md](ROLE_REVIEW.md) | 선택 관점을 반영한 통합 우선순위 |
| 예상 주목도 맵만 | [ATTENTION_MAP.md](ATTENTION_MAP.md) | 예상 주목 영역과 순서, 또는 도구 부재 시 텍스트 설명 |

리뷰 결과는 기본적으로 채팅에 반환합니다. Markdown 보고서 저장, 코드 구현, Figma 편집은 별도 요청이 있어야 합니다. 검토 중에 특정 단어를 수집하거나 별도 메모리·로그에 축적하는 기능은 없습니다. AI 호스트 자체의 대화 기록 정책은 이 Dock이 제어하지 않습니다.

## 준비 조건

- Figma 링크: 현재 AI 환경의 Figma MCP와 해당 파일에 대한 읽기 권한이 필요합니다.
- 스크린샷: 이미지를 읽을 수 있는 AI 환경이 필요합니다.
- 프로토타입 영상: 영상 또는 프레임 확인 도구가 필요합니다. 지원하지 않으면 주요 장면을 이미지로 제공하세요.
- 공개 웹페이지: 브라우저 등 화면 확인 도구가 필요합니다. 읽을 수 없는 페이지는 스크린샷으로 대체합니다.
- 주목도 이미지: 원본 화면을 확인하고 편집할 수 있는 도구가 필요합니다. 지원하지 않으면 텍스트로 예상 순서를 제공합니다.

## 검토 범위

문서 기반 검토이므로 자동 검사 통과나 실제 사용자 검증을 보장하지 않습니다. 화면에 보이지 않는 상태, 동작, 접근성은 미확인으로 구분합니다. 재검토 요청은 현재 결과와 근거를 가이드에 대조하는 방식이며 별도 하네스나 무한 반복을 사용하지 않습니다.
