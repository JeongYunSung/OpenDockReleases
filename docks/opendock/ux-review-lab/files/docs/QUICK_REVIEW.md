# 빠른 UX 점검

처음 이 화면을 보는 사람이 목적을 이해하고 다음 행동을 찾을 수 있는지 확인합니다. 관찰한 화면 범위 안에서 답하고, 실제 사용자 행동을 관측한 것처럼 서술하지 않습니다.

## 살펴볼 질문

- 제목과 주요 정보만으로 이 화면의 목적과 현재 위치를 알 수 있는가?
- 시각적으로 강한 요소가 사용자 목표와 연결되는가? 중요한 안내가 경쟁 요소에 묻히지 않는가?
- 다음 행동과 되돌아갈 경로가 구분되는가? 버튼 문구가 결과를 예상하게 하는가?
- 선택 여부, 필수 입력, 오류, 로딩, 완료 안내가 제공된 자료에서 확인되는가?
- 용어와 정보 순서가 사용자에게 추가 추론이나 반복 입력을 요구하는가?

스크린샷에 오류 상태가 없다는 이유만으로 제품에 오류 처리가 없다고 단정하지 않습니다. 확인되지 않은 상태는 질문 또는 추가 테스트 항목으로 남깁니다.

## 짧은 결과

한 줄 판단 뒤에 잘 전달되는 부분, 혼란 가능성이 있는 부분, 먼저 개선할 항목을 정리합니다. 주요 문제에는 화면 위치와 관찰 근거, 사용자에게 줄 영향, 구체적인 대안을 붙입니다. 실제 테스트에서 확인할 가설은 마지막에 별도로 구분합니다.

역할별 리뷰도 함께 요청되었다면 같은 화면을 다시 설명하지 말고 하나의 결과로 합칩니다.
