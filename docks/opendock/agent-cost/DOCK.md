# Agent Cost

AI를 많이 쓰는데 어디서 비용이 새는지 모르겠다면 작업별 사용량과 성과를 함께 정리해 줍니다. 단순히 싼 모델을 고르는 것이 아니라, 품질을 유지하면서 낭비되는 호출과 긴 컨텍스트를 줄이는 데 초점을 둡니다.

## 이런 때 사용하세요

- 팀이나 프로젝트의 AI 사용 비용을 한눈에 보고 싶을 때
- 같은 작업을 여러 모델로 수행한 비용과 결과를 비교할 때
- 월간 예산을 정하고 초과 원인을 찾을 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-agent-cost` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Agent Cost 기준으로”라고 적어도 됩니다.

### 요청 예시

> 이번 달 AI 사용 내역을 정리하고 비용이 가장 많이 든 작업 3개와 줄일 방법을 알려줘.

> 이 문서 요약 작업을 현재 모델과 저비용 모델로 나눠 실행하는 방안을 비교해줘.

## 검토가 필요할 때

요청에 `검토해줘`라고 덧붙이면 AI가 이 Dock의 기준으로 현재 결과물만 다시 읽고 빠진 내용과 모순을 고칩니다. 별도의 무거운 하네스나 프로젝트 전체 검사는 실행하지 않습니다.

## 사용 후 얻는 것

- 작업별 비용과 품질을 함께 보는 사용 기록
- 예산 초과 원인과 다음 작업부터 적용할 절감안
- 사실과 추정치를 구분한 비용 보고서
