# Creative Generation Ultrawork

대충 그린 도형이나 첫 결과물에 멈추지 않고 목적, 스타일, 구도와 제약을 먼저 정한 뒤 생성 모델로 결과를 만듭니다. 강한 검수를 요청하면 현재 생성물의 크기, 형식, 권리 기록과 품질 기준을 엄격하게 확인합니다.

## 이런 때 사용하세요

- 브랜드 로고나 파비콘을 여러 시안으로 만들 때
- 이미지, 영상, 음성 결과를 같은 콘셉트로 맞출 때
- 기존 리소스를 분석하고 개선 방향을 정할 때

## AI에서 이렇게 사용하세요

AI에서 `$opendock-creative-gen-ultrawork` 스킬을 선택한 뒤 자연어로 요청하세요. 스킬 선택 기능이 없는 AI에서는 요청에 “Creative Generation Ultrawork 기준으로”라고 적어도 됩니다.

### 요청 예시

> OpenDock의 가벼운 조합 이미지를 상징하는 로고 시안 3개를 만들어줘.

> 이번에 만든 로고를 ultrawork로 검수하고 작은 크기 가독성과 배경별 사용성을 고쳐줘.

## 검수 강도

- 평소 요청에서는 지금 만들거나 수정한 결과물에 필요한 기준만 적용해 빠르게 작업합니다.
- 요청에 `검수` 또는 `ultrawork`를 넣으면 현재 결과물에 강한 하네스와 AI 검토를 적용하고, 실패 항목을 고친 뒤 다시 확인합니다.
- 프로젝트 전체 검사는 사용자가 전체 범위를 명확히 요청한 경우에만 실행합니다. 관련 없는 기존 파일 때문에 작업을 늦추지 않습니다.

## 사용 후 얻는 것

- 목적과 스타일이 명확한 생성 프롬프트
- 실제로 사용할 수 있는 이미지, 벡터, 영상 또는 음성 파일
- 현재 결과물에 한정된 품질·안전·권리 확인 기록
